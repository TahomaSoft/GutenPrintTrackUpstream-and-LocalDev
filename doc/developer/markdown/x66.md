::: sect1
# [2.2. Linking with libgutenprint]{#AEN66} {#linking-with-libgutenprint .sect1}

To link a program with libgutenprint, the option `-lgutenprint`{.option}
needs to be passed to the compiler when linking. For example, to compile
and link `stpimage.c`{.filename} the following commands would be used:

``` screen
$ gcc -c stpimage.c
$ gcc -o stpimage -lgutenprint stpimage.o
```

The compiler and linker flags needed may vary depending on the options
Gutenprint was configured with when it was built. The **pkg-config**
script will give the correct parameters for the local installation.
:::
