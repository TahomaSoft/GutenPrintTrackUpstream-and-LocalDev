::: chapter
# []{#AEN47}Chapter 2. Using libgutenprint

This chapter describes how to write programs that use libgutenprint.

::: sect1
# [2.1. Code prerequisites]{#AEN50} {#code-prerequisites .sect1}

To use libgutenprint with a program, several steps must be taken:

-   Include the master libgutenprint header:

    ::: informalexample
    []{#AEN56}
    ``` programlisting
    <gimp-print/gimp-print.h>
    ```
    :::

-   Call `stp_init`{.function}.

-   Link with the libgutenprint library.

The following is a short example program. It does not do anything
useful, but it does everything required to link with libgutenprint and
call other functions from libgutenprint.

::: informalexample
[]{#AEN64}

``` programlisting
#include <gimp-print/gimp-print.h>
int
main (int argc, char *argv[])
{
  stp_init();
  return 0;
}
      
```
