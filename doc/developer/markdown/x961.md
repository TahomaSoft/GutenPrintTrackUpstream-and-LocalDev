# [5.2. Remote Mode Commands]{#AEN961} {#remote-mode-commands .sect1}

The following description of remote commands comes out of an examination
of the sequences used by the printer utilities bundled with the Windows
drivers for the ESC740, and from other sources (some Epson manuals,
experimentation, analysis of print files). It is largely speculative as
these commands are not all documented in the Epson documentation we have
access to. Generally, newer manuals provide more thorough documentation.

Remote command mode is entered when the printer is sent the following
sequence:

::: informalexample
[]{#AEN965}

``` screen
ESC (R BC=8 00 R E M O T E 1
```
:::

Remote mode commands are then sent, and terminated with the following
sequence:

::: informalexample
[]{#AEN968}

``` screen
ESC 00 00 00
```
:::

All remote mode commands must be sent before the initial
`ESC (G`{.literal} command is sent.

This introductory sequence is then followed by a sequence of commands.
Each command is constructed as follows:

1.  Two ASCII bytes indicating the function

2.  A byte count (two bytes, little-endian) for the parameters

3.  Binary parameters, if any

This is a list of all remote commands we have seen:

::: variablelist
**ESC/P2 Remote Mode Commands**

`NC `{.literal}`BC`{.varname}`=2 00 00`{.literal}

:   Print a nozzle check pattern.

`VI `{.literal}`BC`{.varname}`=2 00 00`{.literal}

:   On my 740, prints the following, probably "version information":

    ::: informalexample
    []{#AEN995}
    ``` screen
    W01286 I02382\r\n
    ```
    :::

`* AI `{.literal}`BC`{.varname}`=3 00 00 00`{.literal}

:   Prints a "printer ID". On one 870, prints the following:

    ::: informalexample
    []{#AEN1003}
    ``` screen
    51-51-50-51-49-48\r\n
    ```
    :::

    The Windows driver has a text entry field where this number can be
    entered, but its purpose is unknown.

`* LD `{.literal}`BC`{.varname}`=0`{.literal}

:   Load printer defaults from NVRAM, DIP switches, and/or ROM. This
    apparently does not load factory defaults per se, but any settings
    that are saved. This is commonly used right at the end of each print
    job after the `ESC @`{.literal} printer reset command.

`* CH `{.literal}`BC`{.varname}`=2 00 `{.literal}`xx`{.varname}

:   Perform a head cleaning cycle. The heads to clean are determined by
    parameter `xx`{.varname}:

    ::: table
    []{#AEN1021}
    **Table 5-5. Head cleaning parameters**

      -----------------------------------------------------------------------
      `xx`{.varname}                      Description
      ----------------------------------- -----------------------------------
      `00`{.constant}                     Clean all heads

      `01`{.constant}                     Clean black head

      `02`{.constant}                     Clean color heads
      -----------------------------------------------------------------------
    :::

    While `xx`{.varname} = `00`{.constant} is likely supported by all
    printers, `xx`{.varname} = `01`{.constant} and `02`{.constant} are
    not.

`* DT `{.literal}`BC`{.varname}`=3 00 `{.literal}`xx`{.varname}` 00`{.literal}

:   Print an alignment pattern. There are three patterns, which are
    picked via the choice of `xx`{.varname}. Pattern `0`{.constant} is
    coarse, pattern `1`{.constant} is medium, and pattern `2`{.constant}
    is fine.

`* DA `{.literal}`BC`{.varname}`=4 00 `{.literal}`xx`{.varname}` 00 `{.literal}`yy`{.varname}

:   Set results for the alignment pattern. `xx`{.varname} is the pattern
    (`1`{.constant}\--`3`{.constant}); `yy`{.varname} is the best choice
    from the set (`1`{.constant}\--`7`{.constant} or
    `1`{.constant}\--`15`{.constant}). This does not save to NVRAM, so
    when the printer is powered off, the setting will be lost.

`* SV `{.literal}`BC`{.varname}`=0`{.literal}

:   Save the current settings to NVRAM.

`* RS `{.literal}`BC`{.varname}`=1 01`{.literal}

:   Reset the printer.

`* IQ `{.literal}`BC`{.varname}`=1 01`{.literal}

:   Get ink quantity. This requires direct access to the printer port.
    The return looks like

    ::: informalexample
    []{#AEN1095}
    ``` screen
    IQ:KKCCMMYY
    ```
    :::

    or

    ::: informalexample
    []{#AEN1098}
    ``` screen
    IQ:KKCCMMYYccmm
    ```
    :::

    (for 4-color and 6-color printers respectively), where each pair of
    digits are hexadecimal representations of percent.
:::

The following two commands have been observed on an STP 870.

::: variablelist

`* IR `{.literal}`BC`{.varname}`=2 00 `{.literal}`xx`{.varname}

:   [*Function unknown*]{.emphasis}. This command has been observed on
    an STP 870 with `xx`{.varname}=`03`{.constant} at the start of a job
    and `xx`{.varname}=`02`{.constant} at the end of a job (where it is
    followed by an `LD`{.literal} command). When in roll mode, the
    values change to `xx`{.varname}=`01`{.constant} at the start of a
    job and `xx`{.varname}=`00`{.constant} at the end of a job.

`* FP `{.literal}`BC`{.varname}`=3 00 `{.literal}`pos`{.varname}`[2]`{.literal}

:   Specify the horizontal left margin in units of 1/360 inch. The
    default value for `pos`{.varname} is `0`{.constant}. For borderless
    printing on printers that support it, a value of `-80`{.constant}
    (`FFB0h`{.constant}) should be used.
:::

The commands below are partially documented in the Stylus Pro 9000
manual. Much of this information is interpreted; none is tested.

::: variablelist

`* SN `{.literal}`BC`{.varname}`=3 00 `{.literal}`xx`{.varname}` `{.literal}`yy`{.varname}

:   Select Mechanism Sequence. `xx`{.varname} controls which
    sub-operation is performed. `xx`{.varname}=`00`{.constant} selects
    the "Feed paper sequence setting". `yy`{.varname} can take on the
    following values (on the STP 870, at any rate):

    ::: table
    []{#AEN1145}
    **Table 5-6. Media types**

      -----------------------------------------------------------------------
      `yy`{.varname}                      Media type
      ----------------------------------- -----------------------------------
      `0`{.constant}                      Default

      `1`{.constant}                      Plain paper

      `2`{.constant}                      Postcards

      `3`{.constant}                      Film (photo quality glossy film,
                                          transparencies)

      `4`{.constant}                      Envelopes

      `5`{.constant}                      Plain paper (fast load)

      `6`{.constant}                      Back light film (although this has
                                          been observed with heavyweight
                                          matte paper)

      `7`{.constant}                      Matte paper (observed with 360 dpi
                                          inkjet paper, and photo quality
                                          inkjet paper)

      `8`{.constant}                      Photo paper
      -----------------------------------------------------------------------
    :::

    Experimentation suggests that this setting changes details of how
    the printers\' cut sheet feeder works, presumably to tune it for
    different types of paper.

    `xx`{.varname}=`01`{.constant} controls the platen gap setting;
    `yy`{.varname}=`00`{.constant} is the default,
    `yy`{.varname}=`1`{.constant} or `2`{.constant} are higher settings.

    `xx`{.varname}=`02`{.constant} controls paper loading speed
    (`yy`{.varname}=`0`{.constant} is normal, `1`{.constant} is fast,
    `2`{.constant} is slow). It appears that `1`{.constant} is used when
    printing on "plain paper", "360dpi ink jet paper" or "ink jet
    transparencies", and `yy`{.varname}=`00`{.constant} for all other
    paper type settings.

    `xx`{.varname}=`07`{.constant} controls duplex printing for printers
    with that capability (`yy`{.varname}=`0`{.varname} is default, for
    non-duplex printing; `1`{.constant} is front side of the paper, and
    `2`{.varname} is back side).

    `xx`{.varname}=`09`{.constant} controls zero margin printing on the
    printers with the capability of printing zero-margin on all sides
    (Stylus Photo 780/790, 890, and 1280/1290).
    `yy`{.varname}=`0`{.constant} is the default; `1`{.constant} enables
    zero margin printing.

`* PP `{.literal}`BC`{.varname}`=3 00 `{.literal}`xx`{.varname}` `{.literal}`yy`{.varname}

:   Set Paper Path. `xx`{.varname}=`2`{.constant} indicates manual feed,
    `xx`{.varname}=`3`{.constant} is for roll paper. `yy`{.varname}
    selects "paper path number".

`* AC `{.literal}`BC`{.varname}`=2 00 `{.literal}`xx`{.varname}

:   Set Auto Cutting State. `xx`{.varname}=`0`{.constant} selects auto
    cutting off, `xx`{.varname}=`1`{.constant} selects auto cutting on,
    and `xx`{.varname}=`2`{.constant} indicates horizontal print page
    line on. It appears that with auto cutting on, roll paper is cut
    automatically at the point a formfeed character is sent. The
    formfeed character is normally used to eject a page; with this
    turned on, it also cuts the roll paper. Horizontal print page line
    on prints a narrow line of black dots at the position the paper
    should be cut manually.

`* DR `{.literal}`BC`{.varname}`=4 00 xx `{.literal}`DT2`{.varname}

:   Set Drying Time. `xx`{.varname}=`00`{.constant} sets the drying time
    "per scan" (per pass?); `xx`{.varname}=`01`{.constant} sets the
    drying time per page. `DT`{.varname} indicates the drying time,
    which is in seconds if page mode is used and in milliseconds if scan
    mode is used. `DT`{.varname} must not exceed 3600 seconds in
    per-page mode and 10000 milliseconds in per-scan mode.

`* IK `{.literal}`BC`{.varname}`=2 00 `{.literal}`xx`{.varname}

:   Select Ink Type. `xx`{.varname}=`00`{.constant} selects dye ink.
    Pigment ink is apparently selected by
    `xx`{.varname}=`01`{.constant}. This probably does not apply to the
    consumer-grade printers.

`* PZ BC=2 00 xx`{.literal}

:   Set Pause After Printing. `xx`{.varname}=`00`{.constant} selects no
    pause after printing; `xx`{.varname}=`01`{.constant} selects pause
    after printing. If turned on, the printer is paused after the page
    is ejected (by the FF byte). If cutting is turned on, the printer is
    paused [*after*]{.emphasis} the cutting or printing of the
    horizontal cut line.

`* EX `{.literal}`BC`{.varname}`=6 00 00 00 00 0x14 `{.literal}`xx`{.varname}

:   Set Vertical Print Page Line Mode. `xx`{.varname}=`00`{.constant} is
    off, `xx`{.varname}=`01`{.constant} is on. If turned on, this prints
    vertical trim lines at the left and right margins.

`* EX `{.literal}`BC`{.varname}`=6 00 00 00 00 0x05 `{.literal}`xx`{.varname}

:   Set Roll Paper Mode. If `xx`{.varname} is `0`{.constant}, roll paper
    mode is off; if `xx`{.varname} is `1`{.constant}, roll paper mode is
    on.

`* EX `{.literal}`BC`{.varname}`=3 00 `{.literal}`xx`{.varname}` `{.literal}`yy`{.varname}

:   Appears to be a synonym for the `SN`{.literal} command described
    above.

`* PH `{.literal}`BC`{.varname}`=2 00 `{.literal}`xx`{.varname}

:   Select Paper Thickness. Set the paper thickness `xx`{.varname} in .1
    mm units. This must not exceed `0x10`{.constant} (1.6 mm). If the
    thickness is set "more than" .6 mm (which probably means "at least"
    0.6 mm, since the other case reads "less than 0.5 mm"), the platen
    gap is set high irrespective of the `SN`{.literal} command.

`* PM `{.literal}`BC`{.varname}`=2 00 00`{.literal}

:   [*Function unknown*]{.emphasis}. Used on the STC 3000 at least when
    using roll feed, and on the STP 870 in all print files analysed to
    date.

`* ST `{.literal}`BC`{.varname}`=2 00 `{.literal}`xx`{.varname}

:   Epson\'s STP 750/1200 programming guide refers to the `ST`{.literal}
    command as "Set printer state reply". If `xx`{.varname} is
    `0`{.constant} or `2`{.constant}, the printer will not send status
    replies. If `xx`{.varname} is `1`{.constant} or `3`{.constant}, the
    printer will send status replies. The status replies consist of
    state, error codes, ink leve, firmware version, and warning status.

    The actual reply is documented as

    ::: informalexample
    []{#AEN1347}
    ``` screen
    @BDC ST\r
    ST: xx;
    [ER: yy;]
    IQ: n1n2n3n4;
    [WR: w1,w2...;]
    RV: zz;
    AI:CW:02kkccmmyy, MI:mm
    [TC:tttt;]
    INK:...;
    \f
    ```
    :::

    (`\r`{.literal} is carriage return; `\n`{.literal} is newline;
    `\f`{.literal} is formfeed.)

    `ST`{.literal} is the printer status:

    ::: table
    []{#AEN1355}
    **Table 5-7. Printer status codes**

      -----------------------------------------------------------------------
      Status code                         Description
      ----------------------------------- -----------------------------------
      `00`{.constant}                     Error

      `01`{.constant}                     Self-test

      `02`{.constant}                     Busy

      `03`{.constant}                     Waiting while printing

      `04`{.constant}                     Idle

      `07`{.constant}                     Cleaning/filling ink heads

      `08`{.constant}                     Not yet initialized/filling heads
      -----------------------------------------------------------------------
    :::

    `ER`{.literal}, if provided, is the error status:

    ::: table
    []{#AEN1395}
    **Table 5-8. Printer error codes**

      -----------------------------------------------------------------------
      Error code                          Description
      ----------------------------------- -----------------------------------
      `00`{.constant}                     Fatal Error

      `01`{.constant}                     Interface not selected

      `04`{.constant}                     Paper jam

      `05`{.constant}                     Out of ink

      `06`{.constant}                     Paper out

      `0D`{.constant}                     Paper gap error

      `10`{.constant}                     Maintenance request

      `11`{.constant}                     Tear-off mode selected

      `12`{.constant}                     Double feed error

      `1C`{.constant}                     Cutter position error

      `1D`{.constant}                     Cutter jam

      `1E`{.constant}                     Ink color error

      `23`{.constant}                     Ink combination error
      -----------------------------------------------------------------------
    :::

    `IQ`{.literal} is the amount of ink left, as a (decimal!) percentage
    expressed in hexadecimal. The values are black, cyan, magenta, and
    yellow. 6 and 7 color printers usually specify two or three
    additional values for light cyan, light magenta, and gray. However,
    some low end 6-color printers specify only four values.

    For printers with different ink cartridge options, the following
    additional values may appear:

    ::: table
    []{#AEN1460}
    **Table 5-9. Printer additional ink codes**

      -----------------------------------------------------------------------
      Ink code                            Description
      ----------------------------------- -----------------------------------
      `NA`{.constant}                     Ink cartridge is not inserted

      `RE`{.constant}                     Ink cartridge information cannot be
                                          read

      `WE`{.constant}                     Ink cartridge information cannot be
                                          written

      `CI`{.constant}                     Ink cartridge is inserted, but has
                                          not been read
      -----------------------------------------------------------------------
    :::

    `WR`{.literal}, if provided, is the warning status:

    ::: table
    []{#AEN1488}
    **Table 5-10. Printer warning codes**

      -----------------------------------------------------------------------
      Warning code                        Description
      ----------------------------------- -----------------------------------
      `10`{.constant}                     Black ink low (Photo black on
                                          printers using UltraChrome® ink)

      `11`{.constant}                     Cyan

      `12`{.constant}                     Magenta

      `13`{.constant}                     Yellow

      `14`{.constant}                     Light cyan (presumably)

      `15`{.constant}                     Light magenta (presumably)

      `17`{.constant}                     Gray (with UltraChrome-compatible
                                          printers)

      `18`{.constant}                     Matte black 1 (UltraChrome)

      `19`{.constant}                     Matte black 2 (UltraChrome)
      -----------------------------------------------------------------------
    :::

    `RV`{.literal} is the firmware revision (one byte ASCII).

    `AI`{.literal} is actuator information. These are two byte ASCII
    codes that indicate \`\`ink weight rank ID\'\' of KCMY,
    respectively.

    `TC`{.literal}, if provided, is the total time of cleaning or ink
    filling (?).

    `RC`{.literal}, if provided, is the firmware revision.

    `INK:`{.literal} and `MI`{.literal} are [*not
    documented*]{.emphasis}.

`* SM `{.literal}`BC`{.varname}`=2 00 `{.literal}`xx`{.varname}

:   Set Status Reply Rate. `xx`{.varname} is the repeat interval in
    seconds. If `xx`{.varname} is `0`{.constant}, the status is returned
    only when the printer\'s state changes.

`* ST `{.literal}`BC`{.varname}`=1 01`{.literal}

:   Reply Printer Status. The reply is formatted as follows:

    ::: informalexample
    []{#AEN1562}
    ``` screen
    @BDC PS\r\nST:xx;\f
    ```
    :::

    `\r`{.literal} is carriage return; `\n`{.literal} is newline;
    `\f`{.literal} is formfeed). If `xx`{.varname} (the reply value) is
    `0`{.constant} or `2`{.constant}, automatic status update is
    disabled; if `1`{.constant} or `3`{.constant}, it is enabled.

`* SM `{.literal}`BC`{.varname}`=1 01`{.literal}

:   Reply Printer Status Rate. The reply is formatted as follows:

    ::: informalexample
    []{#AEN1580}
    ``` screen
    @BDC PS\r\nST:xx;\f
    ```
    :::

    `\r`{.literal} is carriage return; `\n`{.literal} is newline;
    `\f`{.literal} is formfeed). See
    `SM `{.literal}`BC`{.varname}`=2`{.literal} above for the meaning of
    the return value.

`* ?? `{.literal}`BC`{.varname}`=`{.literal}`xx`{.varname}` `{.literal}`y`{.varname}`[1] … `{.literal}`y`{.varname}`[xx]`{.literal}

:   Echo Parameters (perhaps better described as Echo Commands). The
    command string is executed (it would appear from the documentation),
    and the string sent is returned using a sequence similar to that
    described in the `ST `{.literal}`BC`{.varname}`=1`{.literal} and
    `SM `{.literal}`BC`{.varname}`=1`{.literal} commands. Note that in
    this case the number of bytes is variable!

`* SM `{.literal}`BC`{.varname}`=2 00 02`{.literal}

:   [*Function unknown*]{.emphasis}. Used on the STC 3000 at least when
    using roll feed.

`* JE `{.literal}`BC`{.varname}`=1 00`{.literal}

:   [*Function unknown*]{.emphasis}. On new printers (STC 740 or newer),
    this command should be sent after all data has been sent. If this
    command is not sent, and the printer is connected to a Windows
    system, the last page of the job will not print completely. The most
    likely explanation for for this is that the Windows driver typically
    puts the printer in 1284.4 packet mode, and this command has the
    effect of flushing the buffer in the printer.

`* CO `{.literal}`BC`{.varname}`=8 00 `{.literal}`cutter`{.varname}`[1] `{.literal}`page`{.varname}`[1] `{.literal}`unit`{.varname}`[1] `{.literal}`position`{.varname}`[4]`{.literal}

:   Specify paper cutting on Stylus Photo 2200 (and perhaps some other
    printers). `cutter`{.varname} must be 0. `page`{.varname} should be
    one of the following:

    ::: table
    []{#AEN1627}
    **Table 5-11. Paper cutting codes**

      -----------------------------------------------------------------------
      Code                                Description
      ----------------------------------- -----------------------------------
      `0`{.constant}                      All pages

      `1`{.constant}                      First page only

      `2`{.constant}                      Last page only
      -----------------------------------------------------------------------
    :::

    `unit`{.varname} should be one of the following:

    ::: table
    []{#AEN1651}
    **Table 5-12. Paper cutting units**

      -----------------------------------------------------------------------
      Code                                Description
      ----------------------------------- -----------------------------------
      `0`{.constant}                      1/360 in.

      `1`{.constant}                      1/720 in.

      `2`{.constant}                      1/1440 in.
      -----------------------------------------------------------------------
    :::

    This command should be used twice. The first `CO`{.literal} command
    specifies where the page will be cut at the top, and the second
    specifies where the page will be cut at the bottom. This permits
    cutting both the top and the bottom of the page.
:::
:::
