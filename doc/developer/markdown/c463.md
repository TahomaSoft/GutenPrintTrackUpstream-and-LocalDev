# []{#AEN463}Chapter 5. ESC/P2

This is a description of the ESC/P2 raster commands used by the
Gutenprint printer driver, which is a subset of the complete command
set. Note that these are [*not*]{.emphasis} always correct, and are
certainly not complete.

All ESCP/2 raster commands begin with the `ESC`{.literal} character
(0x1b), followed by either one or two command characters and arguments
where applicable. Older commands generally have one command character.
Newer commands usually have a '`(`{.literal}' (left parenthesis)
followed by a command character and a byte count for the arguments that
follow. The byte count is a 16-bit (2 byte) binary integer, in little
endian order.

All arguments listed here are of the form `name[bytes]`{.literal} where
`[bytes]`{.literal} is the number of bytes that comprise the argument.
The arguments themselves are usually one, two, or four byte integers,
always little endian (the least significant bits come first). Presumably
this is to match Intel processors.

In some cases, the same command sequence identifies different versions
of the same command, depending upon the number of bytes of arguments.

::: sect1
# [5.1. Standard commands]{#AEN474} {#standard-commands .sect1}

::: variablelist
**ESC/P2 Commands**

`ESC @`{.literal}

:   Reset the printer. Discards any output, ejects the existing page,
    returns all settings to their default. Always use this before
    printing a page.

`ESC (G `{.literal}`BC`{.varname}`=1 `{.literal}`ON1`{.varname}

:   Turn on graphics mode. `ON`{.varname} should be `1`{.constant} (turn
    on graphics mode).

`ESC (U `{.literal}`BC`{.varname}`=1 `{.literal}`UNIT1`{.varname}

:   Set basic unit of measurement used by printer. This is expressed in
    multiples of 1/3600\". At 720 DPI, `UNIT`{.varname} is
    `5`{.constant}; at 360 DPI, `UNIT`{.varname} is `10`{.constant}.

`ESC (U `{.literal}`BC`{.varname}`=5 `{.literal}`PAGEUNITS1`{.varname}` `{.literal}`VUNIT1`{.varname}` `{.literal}`HUNIT1`{.varname}` `{.literal}`BASEUNIT2`{.varname}

:   Set basic units of measurement used by the printer.
    `PAGEUNIT`{.varname} is the unit of page measurement (for commands
    that set page dimensions and the like). `VUNIT`{.varname} is the
    unit of vertical measurement (for vertical movement commands).
    `HUNIT`{.varname} is the unit of horizontal movement (for horizontal
    positioning commands). All of these units are expressed in
    `BASEUNIT`{.varname}, which is in reciprocal inches. Typically,
    `BASEUNIT`{.varname} is `1440`{.constant}. In 720 DPI mode,
    `PAGEUNIT`{.varname}, `VUNIT`{.varname}, and `HUNIT`{.varname} are
    all `2`{.constant}; in 1440×720 DPI mode, `PAGEUNIT`{.varname} and
    `VUNIT`{.varname} are normally set to `2`{.constant};
    `HUNIT`{.varname} is set to `1`{.constant}.

`ESC (K `{.literal}`BC`{.varname}`=2 `{.literal}`ZERO1`{.varname}` `{.literal}`GRAYMODE1`{.varname}

:   Set color or grayscale mode, on printers supporting an explicit
    grayscale mode. These printers can be identified because they are
    advertised as having more black nozzles than nozzles of individual
    colors. Setting grayscale mode allows use of these extra nozzles for
    faster printing. `GRAYMODE`{.varname} should be `0`{.constant} or
    `2`{.constant} for color, `1`{.constant} for grayscale.
    `ZERO`{.varname} should always be `0`{.constant}.

`ESC (i `{.literal}`BC`{.varname}`=1 `{.literal}`INTERLEAVE1`{.varname}

:   If `INTERLEAVE`{.varname} is `1`{.constant}, use printer interleave
    mode (referred to by Epson as \"MicroWeave\". On older printers,
    this is used to turn on printer interleave; on newer printers, it
    prints one row at a time. All printers support this mode. It should
    only be used at 720 (or 1440×720) DPI. The Epson Stylus Pro series
    indicates additional modes (with additional optionss on newer ones):

    ::: variablelist

    `2`{.constant}

    :   "Full-overlap"

    `3`{.constant}

    :   "Four-pass"

    `4`{.constant}

    :   "Full-overlap 2"
    :::

    Any of these commands can be used with the high four bits set to
    either `3`{.constant} or `0`{.constant}.

`ESC U `{.literal}`DIRECTION1`{.varname}

:   If `DIRECTION`{.varname} is `1`{.constant}, print unidirectionally;
    if `0`{.constant}, print bidirectionally.

`ESC (s `{.literal}`BC`{.varname}`=1 `{.literal}`SPEED1`{.varname}

:   On some older printers, this controls the print head speed.
    `SPEED`{.varname} of `2`{.constant} is 10 inches/sec;
    `SPEED`{.varname} of `0`{.constant} or 1 is 20.

`ESC (e `{.literal}`BC`{.varname}`=2 `{.literal}`ZERO1`{.varname}` `{.literal}`DOTSIZE1`{.varname}

:   Choose print dotsize. `DOTSIZE`{.varname} can take on various
    values, depending upon the printer. Almost all printers support
    `0`{.constant} and `2`{.constant}. Variable dot size printers allow
    a value of `16`{.varname}. Other than the value of `16`{.varname},
    this appears to be ignored at resolutions of 720 DPI and above.

`ESC (C `{.literal}`BC`{.varname}`=2 `{.literal}`PAGELENGTH2`{.varname}, `ESC (C `{.literal}`BC`{.varname}`=4 `{.literal}`PAGELENGTH4`{.varname}

:   Set the length of the page in "pageunits" (see `ESC (U`{.literal}
    above). The second form of the command allows setting of longer page
    lengths on new printers (these happen to be the printers that
    support variable dot size).

`ESC (c `{.literal}`BC`{.varname}`=4 `{.literal}`TOP2`{.varname}` `{.literal}`LENGTH2`{.varname}, `ESC (c `{.literal}`BC`{.varname}`=8 `{.literal}`TOP4`{.varname}` `{.literal}`LENGTH4`{.varname}

:   Set the vertical page margins of the page in "pageunits" (see
    `ESC (U`{.literal} above). The margins are specified as the top of
    the page and the length of the page. The second form of the command
    allows setting of longer page lengths on new printers (these happen
    to be the printers that support variable dot size).

`ESC (S `{.literal}`BC`{.varname}`=8 `{.literal}`WIDTH4`{.varname}` `{.literal}`LENGTH4`{.varname}

:   Set the width and length of the printed page region in "pageunits"
    (see `ESC (U`{.literal} above).

`ESC (v `{.literal}`BC`{.varname}`=2 `{.literal}`ADVANCE2`{.varname}, `ESC (v `{.literal}`BC`{.varname}`=4 `{.literal}`ADVANCE4`{.varname}

:   Feed vertically `ADVANCE`{.varname} "vertical units" (see
    `ESC (U`{.literal} above) from the current print head position.

`ESC (V `{.literal}`BC`{.varname}`=2 `{.literal}`ADVANCE2`{.varname}, `ESC (V `{.literal}`BC`{.varname}`=4 `{.literal}`ADVANCE4`{.varname}

:   Feed vertically `ADVANCE`{.varname} "vertical units" (see
    `ESC (U`{.literal} above) from the top margin.

`ESC ($ `{.literal}`BC`{.varname}`=4 `{.literal}`OFFSET4`{.varname}

:   Set horizontal position to `OFFSET`{.varname} from the left margin.
    This command operates on printers of the 740 class and newer (all
    printers with variable dot size).

`ESC $ `{.literal}`OFFSET2`{.varname}

:   Set horizontal position to `OFFSET`{.varname} from the left margin.
    This command operates on printers of the 740 class and newer (all
    printers with variable dot size).

`ESC (\ `{.literal}`BC`{.varname}`=4 `{.literal}`UNITS2`{.varname}` `{.literal}`OFFSET2`{.varname}

:   Set horizontal position to `OFFSET`{.varname} from the previous
    print head position, measured in `UNITS`{.varname}.
    `UNITS`{.varname} is measured in inverse inches, and should be set
    to 1440 in all cases. This operates on all 1440 dpi printers that do
    not support variable dot size.

`ESC (/ `{.literal}`BC`{.varname}`=4 `{.literal}`OFFSET4`{.varname}

:   Set horizontal position to `OFFSET`{.varname} from the previous
    print head position, measured in "horizontal units" (see
    `ESC (U`{.literal} above). This operates on all variable dot size
    printers.

`ESC \ `{.literal}`OFFSET2`{.varname}

:   Set horizontal position to `OFFSET`{.varname} from the previous
    print head position, measured in basic unit of measurement (see
    `ESC (U`{.literal} above). This is used on all 720 dpi printers, and
    can also be used on 1440 dpi printers in lower resolutions to save a
    few bytes. Note that `OFFSET`{.varname} may be negative. The range
    of values for this command is between `-16384`{.constant} and
    `16383`{.constant}.

`ESC r `{.literal}`COLOR1`{.varname}, `ESC (r `{.literal}`BC`{.varname}`=2 `{.literal}`DENSITY1`{.varname}` `{.literal}`COLOR1`{.varname}

:   Set the ink color. The first form is used on four-color printers;
    the second on six-color printers. `DENSITY`{.varname} is
    `0`{.constant} for dark inks, `1`{.constant} for light.
    `COLOR`{.varname} is

    ::: table
    []{#AEN725}
    **Table 5-1. Colors**

      -----------------------------------------------------------------------
      `COLOR`{.varname}                   Color name
      ----------------------------------- -----------------------------------
      `0`{.constant}                      Black

      `1`{.constant}                      Magenta

      `2`{.constant}                      Cyan

      `4`{.constant}                      Yellow
      -----------------------------------------------------------------------
    :::

    This command is not used on variable dot size printers in softweave
    mode.

`ESC . `{.literal}`COMPRESS1`{.varname}` `{.literal}`VSEP1`{.varname}` `{.literal}`HSEP1`{.varname}` `{.literal}`LINES1`{.varname}` `{.literal}`WIDTH2`{.varname}` data...`{.literal}

:   Print data. `COMPRESS`{.varname} signifies the compression mode.

    ::: table
    []{#AEN764}
    **Table 5-2. Compression modes**

      -----------------------------------------------------------------------
      `COMPRESS`{.varname}                Compression mode
      ----------------------------------- -----------------------------------
      `0`{.constant}                      No compression

      `1`{.constant}                      TIFF compression (incorrectly
                                          documented as "run length encoded")

      `2`{.constant}                      TIFF compression with a special
                                          command set.
      -----------------------------------------------------------------------
    :::

    `VSEP`{.varname} depends upon resolution and printer type. At 360
    DPI, it is always `10`{.constant}. At 720 DPI, it is normally
    `5`{.constant}5. On the ESC 600, it is `40`{.constant} (8 × 5}). On
    some other printers, it varies.

    `HSEP1`{.varname} is `10`{.constant} at 360 DPI and `5`{.constant}
    at 720 or 1440 DPI (1440 DPI cannot be printed in one pass; it is
    printed in two passes, with the dots separated in each pass by
    1/720\").

    `LINES`{.varname} is the number of lines to be printed. It should be
    `1`{.constant} in printer interleave and 360 DPI. At 720 DPI
    softweave, it should be the number of lines to be actually printed.

    `WIDTH`{.varname} is the number of pixels to be printed in each row.
    Following this command, a carriage return (`13`{.constant} decimal,
    `0A`{.literal} hex) should be output to return the print head
    position to the left margin.

    The basic data format is a string of bytes, with data from left to
    right on the page. Within each byte, the highest bit is first.

    The TIFF compression is implemented as one count byte followed by
    one or more data bytes. There are two cases:

    1.  If the count byte is `128`{.constant} or less, it is followed by
        (\[count\] + 1) data bytes. So if the count byte is
        `0`{.constant}, it is followed by 1 data byte; if it is
        `128`{.constant}, it is followed by 129 data bytes.

    2.  If the count byte is greater than 128, it is followed by one
        byte. This byte is repeated (257 - \[count\]) times. So if
        \[count\] is 129, the next byte is treated as though it were
        repeated 128 times; if \[count\] is 255, it is treated as though
        it were repeated twice.

`ESC i `{.literal}`COLOR1`{.varname}` `{.literal}`COMPRESS1`{.varname}` `{.literal}`BITS1`{.varname}` `{.literal}`BYTES2`{.varname}` `{.literal}`LINES2`{.varname}` data...`{.literal}

:   Print data in the newer printers (that support variable dot size),
    and Stylus Pro models. `COLOR`{.varname} is the color.

    ::: table
    []{#AEN824}
    **Table 5-3. Extended Colors**

      -----------------------------------------------------------------------
      `COLOR`{.varname}                   Color name
      ----------------------------------- -----------------------------------
      `0`{.constant}                      Black

      `1`{.constant}                      Magenta

      `2`{.constant}                      Cyan

      `4`{.constant}                      Yellow

      `5`{.constant}                      Alternate black (Stylus C70/C80)

      `6`{.constant}                      Alternate black (Stylus C70/C80)

      `16`{.constant}                     Gray ("light black")

      `17`{.constant}                     Light magenta

      `18`{.constant}                     Light cyan
      -----------------------------------------------------------------------
    :::

    `COMPRESS`{.varname} signifies the compression mode:

    ::: table
    []{#AEN873}
    **Table 5-4. Compression modes**

      -----------------------------------------------------------------------
      `COMPRESS`{.varname}                Compression mode
      ----------------------------------- -----------------------------------
      `0`{.constant}                      No compression

      `1`{.constant}                      TIFF compression (incorrectly
                                          documented as "run length encoded")

      `2`{.constant}                      TIFF compression with a special
                                          command set, or "run length
                                          encoding 2" on some printers.
      -----------------------------------------------------------------------
    :::

    `BITS`{.varname} is the number of bits per pixel.

    `BYTES`{.varname} is the number of bytes wide for each row
    (ceiling(BITS × width_of_row, 8)}). Note that this is different from
    the `ESC .`{.literal} command above.

    `LINES`{.varname} is the number of lines to be printed. This command
    is the only way to get variable dot size printing. In variable dot
    mode, the size of the dots increases as the value (`1`{.constant},
    `2`{.constant}, or `3`{.constant}) increases.

`ESC (D `{.literal}`BC`{.varname}`=4 `{.literal}`BASE2`{.varname}` `{.literal}`VERTICAL1`{.varname}` `{.literal}`HORIZONTAL1`{.varname}

:   Set printer horizontal and vertical spacing. It only applies to
    variable dot size printers in softweave mode (and possibly other
    high end printers).

    `BASE`{.varname} is the base unit for this command; it must be
    `14400`{.constant}.

    `VERTICAL`{.varname} is the distance in these units between printed
    rows; it should be ((separation_in_nozzles × `BASE`{.varname} ÷
    720).

    `HORIZONTAL`{.varname} is the horizontal separation between dots in
    a row. Depending upon the printer, this should be either (14400
    ÷ 720) or (14400 ÷ 360). The Stylus Pro 9000 manual suggests that
    the settings should match the chosen resolution, but that is
    apparently not the case (or not always the case) on other printers.

`ESC (g `{.literal}`BC`{.varname}`=4 `{.literal}`CUTPOS`{.varname}

:   Only seen on roll-only printers like the SureLab D700, this tells
    the printer where to actuate the cutter, eject the page, and cease
    printing.

    `CUTPOS`{.varname} The row number at which to actuate the cutter. It
    is resolution-indepenent, specified in 1/2880 in. units.

`ESC (g `{.literal}`BC`{.varname}`=8 00 R E M O T E 1`{.literal}

:   Enters "remote mode". This is a special, undocumented command set
    that is used to set up various printer options, such as paper feed
    tray, and perform utility functions such as head cleaning and
    alignment. It does not appear that anything here is actually
    required to make the printer print. Our best understanding of what
    is in a remote command sequence is described in a separate section
    below.

`ESC 01 @EJL [sp] ID\r\n`{.literal}

:   Return the printer ID. This is considered a remote mode command,
    although the syntax is that of a conventional command. This returns
    the following information:

    ::: informalexample
    []{#AEN943}
    ``` screen
    @EJL ID\r
    MFG:EPSON;
    CMD:ESCPL2,BDC;
    MDL:[printer model];
    CLS:PRINTER;
    DES:EPSON [printer model];
    \f
    ```
    :::

    After all data has been sent, a form feed byte should be sent.
:::

All newer Epson printers (STC 440, STP 750) require the following
command to be sent at least once to enable printing at all. This command
specifically takes the printer out of the 1284.4 packet mode
communication protocol and enables normal data transfer. Sending it
multiple times is is not harmful, so it is normally sent at the
beginning of each job:

::: informalexample
[]{#AEN947}

``` screen
ESC 01@EJL[space]1284.4[newline]@EJL[space][space][space][space]
[space][newline]ESC@
```
:::

The proper sequence of initialization commands is:

::: informalexample
[]{#AEN950}

``` screen
magic command
ESC @
remote mode if needed
ESC (G
ESC (U
ESC (K (if appropriate)
ESC (i
ESC U (if needed)
ESC (s (if appropriate)
ESC (e
ESC (C
ESC (c
ESC (S
ESC (D (if needed)
ESC (V (optional -- this can be accomplished with ESC (v)
```
:::

For printing, the proper sequence is:

::: informalexample
[]{#AEN953}

``` screen
ESC (v
```
:::

and repeat for each color:

::: informalexample
[]{#AEN956}

``` screen
ESC ($ or ESC (\ or ESC \
ESC (r or ESC r (if needed---not used with "ESC i" and not needed if the color
has not changed from the previous printed line)
ESC . or ESC i  ...data... [return] (0A hex)
```
:::

To terminate a page:

::: informalexample
[]{#AEN959}

``` screen
[formfeed] (0C hex)
ESC @
```
:::
